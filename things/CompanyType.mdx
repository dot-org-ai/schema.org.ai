# CompanyType

A CompanyType is a canonical *archetype* of a company — distinct from a specific [Business](Business.mdx) instance (Acme Accounting Co.) and from an [Industry](Industry.mdx) (which is broader and just classifies activity). CompanyTypes encode three derivation axes:

1. **Industry** — NAICS sector
2. **Business model** — fee-for-service / subscription / marketplace / etc.
3. **Regulatory regime** — licensed / unlicensed / regulated-jurisdictional

Examples: Accounting Firm (Industry: Accounting, Tax Preparation; Model: fee-for-service; Regime: licensed CPA). Plumbing Contractor (Industry: Plumbing/HVAC; Model: project-based; Regime: licensed trade). Boutique Hotel (Industry: Traveler Accommodation; Model: room-night; Regime: hospitality-licensed).

CompanyType is the addressable archetype that downstream cascade content (Problems, Opportunities, Startups) reasons about — "what problems do Accounting Firms have?" generates differently than "what problems does Acme Accounting have?"

| `revenueRange` | Text | Typical annual revenue order-of-magnitude | CompanyType |

## Examples

### Example 1: Accounting Firm

```typescript
import type { CompanyType } from 'schema.org.ai'

const accountingFirm: CompanyType = {
  $type: 'CompanyType',
  $id: 'https://companytypes.org.ai/Accounting_Firm',
  name: 'Accounting Firm',
  description: 'Professional services firm providing accounting, tax, and audit services to clients.',
  industry: 'https://industries.org.ai/Accounting_Tax_Preparation',
  businessModel: 'fee-for-service',
  regulatoryRegime: 'licensed',
  departments: ['Tax', 'Audit', 'Advisory'],
  jobTypes: ['Staff_Bookkeeper', 'Tax_Manager', 'Audit_Partner'],
  revenueRange: '$500K–$50M',
}
```

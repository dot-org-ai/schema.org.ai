# DigitalProperty

A digital property is the unifying type for things-with-URLs — addressable entities that have a stable digital presence and can be referenced, linked, or transacted with via a URL. Websites, web apps, API endpoints, deployed AI agents, mobile apps, Cloudflare Workers, datasets — all are DigitalProperties.

Distinct from the scalar `digital` property (a 0.0–1.0 maturity score on any Thing). DigitalProperty is *the type for entities that are themselves digital*; `digital` is *a measurement of how digital any Thing is*. Both can coexist on the same Thing: an Agent (DigitalProperty) has `digital: 1.0`; a hybrid Business may be a DigitalProperty with `digital: 0.6` because its core operations span digital and physical.

## Properties

| Property | Type | Description | Inherited From |
|----------|------|-------------|----------------|
| `$type` | Text | Always "DigitalProperty" or a subtype | - |
| `$id` | URL | The canonical URL of the property | Thing |
| `name` | Text | Display name | Thing |
| `description` | Text | What this property is/does | Thing |
| `url` | URL | The serving URL (may differ from `$id`) | Thing |
| `owner` | Person or Organization | Who owns the property | DigitalProperty |
| `provider` | Organization | Hosting/serving provider | DigitalProperty |
| `tld` | Text | Top-level domain (e.g. "do", "org.ai", "studio") | DigitalProperty |
| `monetized` | Boolean | Whether the property generates revenue | DigitalProperty |
| `digital` | Number | 0.0–1.0 — typically 1.0 for DigitalProperty | Thing |

## Examples

### Example 1: A deployed agent

```typescript
import type { DigitalProperty } from 'schema.org.ai'

const priyaAgent: DigitalProperty = {
  $type: ['Agent', 'DigitalProperty'],
  $id: 'https://schema.org.ai/Agent/Priya',
  name: 'Priya — Product Marketing Agent',
  url: 'https://priya.do',
  owner: 'https://platform.do',
  provider: 'https://workers.do',
  tld: 'do',
  monetized: true,
  digital: 1.0,
}
```

### Example 2: A canonical-reference subdomain

```typescript
const schemaOrgAi: DigitalProperty = {
  $type: 'DigitalProperty',
  $id: 'https://schema.org.ai',
  name: 'schema.org.ai',
  description: 'Canonical AI-era superset of schema.org.',
  tld: 'org.ai',
  monetized: false,  // ads in sidebar but not the purpose
  digital: 1.0,
}
```

### Example 3: A Business as a portfolio of DigitalProperties

```typescript
const acmeBusiness = {
  $type: 'Business',
  name: 'Acme Analytics',
  properties: [
    'https://acme.io',                  // marketing site
    'https://app.acme.io',              // SaaS app
    'https://api.acme.io',              // public API
    'https://docs.acme.io',             // documentation
  ],
}
```

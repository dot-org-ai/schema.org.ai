# Opportunity

> **Overlay-first (not a schema.org.ai native).** Ruled by Nathan on org.ai issue #11 (2026-07-18), verbatim: *"Opportunity, Market → overlay-first (once demoted in-monorepo per ADR 0057 = negative fixation evidence; graduate per R5)"*. Opportunity is homed in the **startups.studio venue overlay** (`https://startups.studio/Opportunity`) — a fast-clock lease with no durability promise — and enters the frozen schema.org.ai profile only by R5 graduation.

An Opportunity is the where-to-build artifact in the Business-as-Code cascade: a [Problem](Problem.mdx) coupled with a [Thesis](Thesis.mdx) approach (Service-as-Software / Agent / Headless SaaS) and a target ICP, scoped to a buildable solution space.

Opportunities are not yet Startups — they're the addressable hypothesis-space cell. Multiple [Startups](https://explore.startups.studio/Startups) can compete in the same Opportunity, each with different differentiation (tier, wedge, GTM, brand). The Combinator generates Startups from Opportunities.

Distinct from a Lead (a specific prospect) or from a Deal (a specific commercial engagement) — an Opportunity is the typed market space.

| `wedge` | Text | The crisp first-foothold pitch | Opportunity |
| `candidateStartups` | Thing[] | Startups exploring this Opportunity | Opportunity |

## Examples

### Example 1: AI Bookkeeping for Small Accounting Firms

```typescript
import type { Opportunity } from 'schema.org.ai'

const aiBookkeepingForFirms: Opportunity = {
  $type: 'Opportunity',
  $id: 'https://opportunities.org.ai/AI_Bookkeeping_for_Accounting_Firms',
  name: 'AI Bookkeeping for Small Accounting Firms',
  description: 'Replace junior-bookkeeper time on reconciliations with an AI service that handles ledger maintenance + AR/AP + bank reconciliation for client engagements.',
  problem: 'https://problems.org.ai/Reconcile_Bank_Statements',
  thesis: 'https://theses.org.ai/Service-as-Software',
  icp: 'https://companytypes.org.ai/Accounting_Firm × revenue $1M-$25M',
  tam: '$8B (US small/mid accounting firm bookkeeping spend)',
  sam: '$1.2B (firms ≤50 staff)',
  incumbents: ['Bench', 'Pilot', 'Botkeeper'],
  wedge: 'White-labeled AI bookkeeping that the firm sells as their own to clients — they keep the relationship, we handle the work.',
  candidateStartups: [
    'https://startups.studio/Startups/LedgerLoop',
    'https://startups.studio/Startups/Ledgerly',
  ],
}
```

### Example 2: AI SDR for Outbound Sales

```typescript
const aiSDR: Opportunity = {
```

### Example 3: Headless SaaS approach to same Problem

```typescript
const headlessReconciliation: Opportunity = {
  $type: 'Opportunity',
  name: 'Reconciliation-as-an-API for Embedded Finance',
  problem: 'https://problems.org.ai/Reconcile_Bank_Statements',  // same Problem as Example 1
  thesis: 'https://theses.org.ai/Headless_SaaS',                  // different Thesis
  icp: 'https://companytypes.org.ai/Fintech_Embedded × Developer',
  wedge: 'API-first reconciliation engine that fintechs embed in their own products.',
}
```

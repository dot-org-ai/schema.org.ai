# Industry

A canonical Industry — a taxonomic classification of economic activity, typically anchored to a standards body's industry code (NAICS in North America, ISIC globally, SIC legacy). Distinct from a specific [Business](Business.mdx) (which is an *instance* of an Organization operating within an Industry) and from a [CompanyType](CompanyType.mdx) (which is a more specific archetype derived from Industry × business model × regulatory regime).

Industry is the broadest dimension in the Business-as-Code cascade. Two soybean farms in different countries belong to the same Industry; same NAICS code 111110. Industry exists *before* and *outside* any particular company.

| `parentIndustry` | Industry | More-general industry (e.g. Oilseed Farming for Soybean Farming) | Industry |
| `childIndustries` | Industry[] | More-specific industries within this one | Industry |
| `sameAs` | URL[] | Wikipedia / Wikidata / official-classification URLs | Thing |
| `companyTypes` | CompanyType[] | Archetype companies within this industry | Industry |

## Examples

### Example 1: NAICS Industry

```typescript
import type { Industry } from 'schema.org.ai'

const soybeanFarming: Industry = {
  $type: 'Industry',
  $id: 'https://industries.org.ai/Soybean_Farming',
  name: 'Soybean Farming',
  description: 'Farming establishments primarily engaged in growing soybeans.',
  code: '111110',
  codeSystem: 'NAICS-2022',
  parentIndustry: 'https://industries.org.ai/Oilseed_Farming',
  sameAs: [
    'https://www.census.gov/naics/?input=111110',
    'https://en.wikipedia.org/wiki/Soybean',
  ],
}
```

### Example 2: Software publishing

```typescript
const softwarePublishing: Industry = {
  $type: 'Industry',
  name: 'Software Publishers',
  code: '513210',
  codeSystem: 'NAICS-2022',
  childIndustries: ['https://industries.org.ai/SaaS_Vendors'],
}
```

### Example 3: As a Business's parent classification

```typescript
const acme = {
  $type: 'Business',
  name: 'Acme Analytics',
  industry: 'https://industries.org.ai/Software_Publishers',
  // Acme is an *instance* of an Organization within this Industry
}
```

# Problem

A canonical market Problem — the pain a sufficiently-pinned Ideal Customer Profile (ICP) exposes. Addressable as a typed entity so multiple candidate Solutions can be enumerated under one Problem, separated by competitive differentiator × Position.

Distinct from schema:Issue (content-issue/dispute) — a Problem is a market problem. Distinct from Bug (software defect). Problems are the demand-side currency of the Business-as-Code cascade: identify a sharp Problem with a clear ICP, and Solutions / Startups follow.

## Properties

| Property | Type | Description | Inherited From |
|----------|------|-------------|----------------|
| `$type` | Text | Always "Problem" | - |
| `name` | Text | Problem statement (e.g. "Manual bank reconciliation eats junior staff time") | Thing |
| `description` | Text | What the pain is | Thing |
| `icp` | Text | The ICP that exposes this Problem (Coordinate or text) | Problem |
| `surfaceTask` | Task | The Task that most surfaces this Problem | Problem |
| `costOfStatusQuo` | Text | What the Problem costs today (in time, money, risk) | Problem |
| `currentWorkaround` | Text | How the ICP solves it today | Problem |
| `severity` | Number | 0.0–1.0 — how acute the pain is | Problem |
| `urgency` | Number | 0.0–1.0 — how time-pressured solving it is | Problem |
| `candidateSolutions` | Thing[] | Candidate Solutions (Coordinate references) | Problem |

## Examples

### Example 1: Bookkeeping reconciliation pain

```typescript
import type { Problem } from 'schema.org.ai'

const reconciliationPain: Problem = {
  $type: 'Problem',
  $id: 'https://problems.org.ai/Reconcile_Bank_Statements',
  name: 'Manual bank reconciliation eats junior staff time at small accounting firms',
  icp: 'https://companytypes.org.ai/Accounting_Firm × https://jobtypes.org.ai/Staff_Bookkeeper',
  surfaceTask: 'https://tasks.org.ai/Reconcile_Bank_Statements',
  costOfStatusQuo: '~30% of staff bookkeeper time, $45K-$65K per bookkeeper annually',
  currentWorkaround: 'QuickBooks bank feeds + manual exception handling',
  severity: 0.7,
  urgency: 0.5,
}
```

const customerHealthVisibility: Problem = {

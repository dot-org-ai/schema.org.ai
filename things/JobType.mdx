# JobType

A JobType is a specific role *within* a [CompanyType](CompanyType.mdx) — derived from the cross-product of [Occupation](https://schema.org/Occupation) (what work is done) and CompanyType (where it's done). Sits between the abstract Occupation and a concrete Job posting.

Examples:
- **Occupation**: Bookkeeper (O\*NET 43-3031.00)
- **CompanyType**: Accounting Firm
- **JobType**: Staff Bookkeeper at an Accounting Firm

Same Occupation can map to many JobTypes — "Bookkeeper at a Small Business" vs "Staff Bookkeeper at an Accounting Firm" vs "AR/AP Specialist at a Manufacturer" — each has different responsibilities, tools, KPIs even though the underlying Occupation is one.

## Properties

| Property | Type | Description | Inherited From |
|----------|------|-------------|----------------|
| `$type` | Text | Always "JobType" | - |
| `name` | Text | Role-archetype name (e.g. "Staff Bookkeeper") | Thing |
| `description` | Text | What the role does in this context | Thing |
| `occupation` | Occupation | Parent O*NET occupation | JobType |
| `companyType` | CompanyType | Parent CompanyType | JobType |
| `department` | Department | Functional area | JobType |
| `tasks` | Task[] | Typical tasks performed | JobType |
| `skills` | Skill[] | Required skills | Occupation |
| `salaryRange` | Text | Typical salary band | JobType |
| `seniority` | Text | "Entry" / "Mid" / "Senior" / "Manager" / "Director" / "Executive" | JobType |

## Examples

### Example 1: Staff Bookkeeper at an Accounting Firm

```typescript
import type { JobType } from 'schema.org.ai'

const staffBookkeeper: JobType = {
  $type: 'JobType',
  $id: 'https://jobtypes.org.ai/Staff_Bookkeeper',
  name: 'Staff Bookkeeper',
  description: 'Entry-level role at an accounting firm responsible for ledger maintenance, reconciliations, and AP/AR for client engagements.',
  occupation: 'https://occupations.org.ai/Bookkeeping_Accounting_and_Auditing_Clerks',
  companyType: 'https://companytypes.org.ai/Accounting_Firm',
  department: 'https://departments.org.ai/Tax',
  seniority: 'Entry',
  salaryRange: '$42K-$55K',
  tasks: [
    'https://tasks.org.ai/Reconcile_Bank_Statements',
    'https://tasks.org.ai/Process_Invoices',
    'https://tasks.org.ai/Maintain_General_Ledger',
  ],
}
```


# CLI

A Command-Line Interface tool — an executable binary that exposes operations as terminal commands. CLIs are the developer-facing counterpart to SDKs: same underlying API, different interaction modality. AI agents increasingly use CLIs because they're scriptable, composable via pipes, and well-documented through `--help`.

## Examples

### Example 1: GitHub CLI

```typescript
import type { CLI } from 'schema.org.ai'

const ghCLI: CLI = {
  $type: 'CLI',
  $id: 'https://schema.org.ai/CLI/gh',
  name: 'GitHub CLI',
  description: 'Manage GitHub issues, PRs, releases from the terminal.',
  binary: 'gh',
  installer: 'brew install gh',
  runtime: 'Go',
  commands: ['gh issue create', 'gh pr view', 'gh release create', 'gh repo clone'],
  documentationUrl: 'https://cli.github.com/manual/',
  wraps: 'https://schema.org.ai/API/GitHub',
}
```

const wranglerCLI: CLI = {

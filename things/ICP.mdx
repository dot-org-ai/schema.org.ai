# ICP

An ICP (Ideal Customer Profile) describes the ideal customer for a [Startup](Startup.mdx) using the structured **as/at/are/using/to** framework:

- **as** — persona/role description (who they are)
- **at** — company/context description (where they work)
- **are** — current state and pain points (their situation)
- **using** — current solutions (what they use today)
- **to** — desired outcome / job to be done (what they want to achieve)

The framework forces a startup to articulate its target customer concretely enough to drive product and marketing decisions.

# Worker

A Worker is the base type for anything that executes work: `Worker { type: 'agent' | 'human' }` with a status, a set of capabilities, and a reference to its current task. [Agent](Agent.mdx)s and humans are both Workers — the interface over them is uniform (`notify` / `ask` / `approve` / `decide` / `do`), which is what lets a [Role](Role.mdx) be filled by either kind and a [Team](Team.mdx) mix both.

# API

A programmatic interface for accessing a service — typically a REST, gRPC, or GraphQL endpoint. APIs expose typed Operations (each a Capability) that AI agents and applications can invoke. The AI-era extension over schema:WebAPI adds richer operation typing, OpenAPI binding, and auth-method declarations so Agents can autonomously discover and use APIs.

## Properties

| Property | Type | Description | Inherited From |
|----------|------|-------------|----------------|
| `$type` | Text | Always "API" | - |
| `name` | Text | Human-readable API name | Thing |
| `description` | Text | What the API does | Thing |
| `baseUrl` | URL | Root URL for API requests | API |
| `protocol` | Text | "REST" / "GraphQL" / "gRPC" / "JSON-RPC" | API |
| `openAPIUrl` | URL | OpenAPI 3.x spec URL | API |
| `auth` | Text | "OAuth2" / "APIKey" / "Bearer" / "None" | API |
| `operations` | Capability[] | Available operations | API |
| `provider` | Organization | API provider | WebAPI |
| `digital` | Number | 1.0 (APIs are fully digital) | Thing |

## Examples

### Example 1: REST API

```typescript
import type { API } from 'schema.org.ai'

const stripeAPI: API = {
  $type: 'API',
  $id: 'https://schema.org.ai/API/Stripe',
  name: 'Stripe API',
  description: 'Payment processing API.',
  baseUrl: 'https://api.stripe.com/v1',
  protocol: 'REST',
  openAPIUrl: 'https://raw.githubusercontent.com/stripe/openapi/master/openapi/spec3.json',
  auth: 'Bearer',
  operations: ['Charges.Create', 'Customers.Retrieve', 'Subscriptions.List'],
}
```

### Example 2: GraphQL API

```typescript
const githubAPI: API = {
  $type: 'API',
  name: 'GitHub GraphQL API',
  baseUrl: 'https://api.github.com/graphql',
  protocol: 'GraphQL',
  auth: 'Bearer',
  description: 'Repository, issues, PR access via GraphQL.',
}
```

### Example 3: AI-Native API (MCP-compatible)

```typescript
const supabaseAPI: API = {
  $type: 'API',
  name: 'Supabase Data API',
  baseUrl: 'https://my-project.supabase.co/rest/v1',
  protocol: 'REST',
  auth: 'APIKey',
  operations: ['Table.Select', 'Table.Insert', 'Function.Invoke'],
}
```

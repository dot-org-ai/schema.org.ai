# SDK

A Software Development Kit — a language-specific library that wraps an API or platform so developers can use it idiomatically from within their applications. SDKs provide typed clients, ergonomic helpers, and language-conventional patterns (async/await, generators, classes) that raw API calls don't.

### Example 1: Anthropic TypeScript SDK

```typescript
import type { SDK } from 'schema.org.ai'

const anthropicTSSDK: SDK = {

  $id: 'https://schema.org.ai/SDK/anthropic-ai-sdk',

  language: 'TypeScript',
  package: '@anthropic-ai/sdk',
  version: '0.30.x',

}
```
